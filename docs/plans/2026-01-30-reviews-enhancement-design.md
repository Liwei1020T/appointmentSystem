# 评价系统增强设计

**日期**: 2026-01-30
**状态**: 已确认

---

## 概述

增强评价系统，让用户可以查看所有公开评价、点赞互动，并支持匿名发布。

## 核心需求

1. 在 `/reviews` 页面添加"全部评价" Tab
2. 用户可以给评价点赞（简单心形图标）
3. 匿名评价显示"匿名用户"，完全隐藏身份
4. 支持按评分筛选和按时间/评分/点赞数排序

### 点赞规则

- 用户不能给自己的评价点赞
- 未登录用户可看到点赞数，点击提示登录
- 点赞后即时更新 UI（乐观更新）

### 匿名显示

- `isAnonymous: true` 时显示"匿名用户"
- 不显示头像（使用默认占位）
- 完全不透露任何用户信息

## API 设计

### 扩展 GET /api/reviews/public

```typescript
// 请求
GET /api/reviews/public?sort=latest&rating=5&page=1&limit=10

// 参数
sort: 'latest' | 'rating' | 'likes'
rating: 1 | 2 | 3 | 4 | 5 (可选)
page: number
limit: number

// 响应
{
  reviews: [{
    id, rating, comment, photos, tags,
    isAnonymous, likesCount, isLiked,
    user: { name, avatar } | null,
    createdAt, adminReply, adminReplyAt
  }],
  pagination: { page, limit, total, totalPages },
  summary: {
    total: 32,
    byRating: { 5: 20, 4: 8, 3: 2, 2: 1, 1: 1 }
  }
}
```

### 点赞 API（已存在）

```typescript
POST /api/reviews/[id]/like
// 响应
{ liked: boolean, likesCount: number }
```
